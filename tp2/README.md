## 1. STATISTICS

Le code contient un algorithme de tri de complexité d'execution $\mathcal{O}(n \times log(n)) $ et de complexité spatiale $ \mathcal{O}(1) $.

La valeur $p95$ correspond à l'élément à l'index $ \lfloor 95  \% \times N \rfloor $ si $N$ est la taille de la liste passée en paramètre. 
Si $ \lfloor 95  \% \times N \rfloor = N $, on utilisera $N - 1$ comme index pour $p95$.
